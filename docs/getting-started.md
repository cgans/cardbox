# Jamo's Dugout: Getting Started

_Last updated Oct 31, 2026_

## What it is

Jamo's Dugout is a private website where Jameson logs his baseball cards and sees what they're worth. The address is **https://jamosdugout.com**. It works on a phone, tablet, or computer; no app to install. Only people Uncle Chris has added can get in, so it's safe to let Jamo use it on his own.

Uncle Chris built it for Jamo and pays for the card-price service behind it, and it's free for the family to use.

## Logging in the first time

The site is tied to **heathergans@gmail.com**, so Jamo logs in with your email and you approve it from your inbox. There is no password.

1. On Jamo's device, open **https://jamosdugout.com** in the browser (Chrome, Safari, whatever he uses).
2. A Cloudflare page asks for an email address. Type `heathergans@gmail.com` and tap **Send me a code**.
3. Check your Gmail for a message from Cloudflare with a 6-digit code (look in Spam/Promotions if it's not there within a minute).
4. Type the code on Jamo's device. The site opens.

The login lasts **7 days** on that device. After that it asks for the email again and a new code comes to you. If Jamo uses a second device, each device needs its own code.

Tip: once it's open, add it to his home screen (Chrome: menu → **Add to Home screen**; Safari: share button → **Add to Home Screen**) so it looks like an app.

## The token question on first visit

The first time the site opens on a device, a box titled **Your SportsCardsPro token** appears. Tap **Use shared default for now**. That's it.

What it means: card prices come from a paid service called SportsCardsPro. Uncle Chris's subscription is already wired in, so Jamo doesn't need his own. The box exists for friends who use the site later (see below). If you tap it by mistake and the box goes away, nothing is lost.

## Adding the first card

The page opens with a few sample cards so he can see how it looks. They disappear the moment he adds a real one.

1. Tap **Add card** (top right).
2. In the search box, type the year, brand, and player from the card, like `1989 Upper Deck Griffey`, and tap **Look up**. The year and brand are printed on the back of the card.
3. Tap the matching result. The year, set, player, and card number fill in, and a price appears in **Value**.
4. Set **Grade**. Most kids' cards are **Raw** (not professionally graded). Only change this if the card is in a sealed PSA or BGS case with a number on the label.
5. **Qty**: how many copies he has.
6. **Paid (each)**: what it cost, if he knows. Leave it blank for cards from a pack or a gift.
7. Tap **Save**.

If the search finds nothing, he can type the fields by hand and enter a value himself. Each saved card has an **eBay comps** button that opens recent sold listings, which is a good way to pick a fair number.

To fix a mistake, tap **Edit** on the card. Changing the grade or any detail re-checks the price automatically.

## What the numbers mean

The tiles across the top update as cards are added.

| Tile | Meaning |
| --- | --- |
| Collection value | What all his cards are worth today, added up |
| Cost basis | What he paid for them, added up |
| Unrealized gain | Value minus cost. Green means the collection is worth more than he paid |
| Cards | How many cards (and how many different ones) |
| Top card | His single most valuable card |

**Value by set** shows which sets hold the most value. **Collection value over time** adds a dot every time prices are refreshed, so after a few weeks he can see whether his collection is going up or down.

Prices are estimates from recent sales. They move, sometimes a lot, and a card's real value is whatever someone pays for it. The **Refresh prices** button re-checks every card; once a week or so is plenty.

## Keeping his collection safe

This is the one thing to know: **his cards are saved on the device he uses, inside that browser.** They are not stored on the internet. That means:

- If he uses a tablet and then a phone, each one has its own separate list.
- If the browser's data gets cleared, or the device is replaced, the list is gone unless there's a backup.

Backing up takes a minute. Do it after any big batch of cards, and before switching devices:

1. Tap **Import / export**.
2. Tap **Copy**. The whole collection is now on the clipboard as text.
3. Paste it somewhere safe: an email to yourself, a note in Google Keep, anywhere. Put the date in the subject.

To restore (or move to a new device): open the site there, tap **Import / export**, paste the saved text into the box, tap **Import pasted JSON**. Everything comes back, including the value history.

Pick one device as "his" and keep it there. Moving between devices works, but it's manual.

## Friends who want to use it

Jamo can show it to anyone, but a friend can only log in if Uncle Chris adds their email first. Send him the friend's (or their parent's) email address and he'll add it the same day.

Two things to pass along to the friend's parents:

- **They should get their own SportsCardsPro token.** The shared default is Uncle Chris's paid subscription, meant for Jamo. A friend who is going to use it regularly should sign up at [sportscardspro.com](https://www.sportscardspro.com), find the token under Subscription → API/Download, and paste it into **Settings** at the bottom of the site. Until they do, "Use shared default for now" still works, so nobody is blocked.
- **Their cards save on their own device**, same as Jamo's. Nobody sees anyone else's collection.

## When something goes wrong

| What you see | What to do |
| --- | --- |
| Login code never arrives | Check Spam and Promotions in Gmail. Wait a minute and tap **Resend**. If it still doesn't come, text Uncle Chris. |
| "You don't have access" page | The email was typed wrong, or it's not on the list. Try again with `heathergans@gmail.com` exactly. |
| Search finds nothing | Check spelling (McGwire, not McGuire). Try fewer words: just the player's last name. Some cards aren't in the price service; type the details by hand. |
| Value shows $0.00 after a lookup | The price service has no price for that grade. Use **eBay comps** and type a value. |
| "Lookup failed" message | Usually a brief internet hiccup. Wait and tap **Look up** again. If it keeps happening, text Uncle Chris. |
| Cards disappeared | Browser data was cleared or he's on a different device. Restore from the last backup (section above). |

Anything else: text Uncle Chris with a screenshot. Screenshots work in a normal browser tab; a private/incognito tab shows up black.
